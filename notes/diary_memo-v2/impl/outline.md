# 日記型メモ一覧 v2 実装計画

`spike/diary-memo-v2` で作った一覧の作り直しを、`main` で少しずつ作り直す。

- 1 step = 1 commit = 1つの目的
- お手本は常に `spike/diary-memo-v2` のコード
- 実装中の調整で spike と違ってよい。ただし、やり残し・検討漏れは無くす
- spike で試して戻した変更（丸を1日1つにする、半透明の線、つまみを縦線の左右に分けて描く、日付を本文の色にする）は通らず、最終形へ直接向かう
- 各 step は `phaseN/stepNN_名前/` に置く（計画は `plan.md`。説明資料の HTML は、頼んだときだけ作る）

---

## 全体の流れ

```text
Phase 1  選択機能をなくす
Phase 2  線の見た目を変える
Phase 3  本文を右端まで広げる
Phase 4  選んだ文字を削除する
Phase 5  仕様書
```

---

## Phase 1 選択機能をなくす

先に消しておき、あとの step で選択中の見た目（太い線・大きい丸・太字）を気にしなくて済むようにする。


| step | やること |
| ---- | ------------------------------------------------------------ |
| 1    | 選択バーとメモの選択をなくす |
| 2    | 使わなくなった削除のしくみを消す |


## Phase 2 線の見た目を変える


| step | やること |
| ---- | ------------------------------------------------------------ |
| 3    | 線と日付の色をそろえる |
| 4    | 丸を日付の区切り線に変える |
| 5    | 線とつまみを細くする |


## Phase 3 本文を右端まで広げる


| step | やること |
| ---- | ------------------------------------------------------------ |
| 6    | 本文を縦線の上まで広げる |
| 7    | つまみと文字選択を見分ける |


※ step 6 の後は、つまみの上だけ文字選択ができない。step 7 で解消する。

## Phase 4 選んだ文字を削除する


| step | やること |
| ---- | ------------------------------------------------------------ |
| 8    | 選んだ文字を削除する |


## Phase 5 仕様書


| step | やること |
| ---- | ------------------------------------------------------------ |
| 9    | 仕様書を直す |
