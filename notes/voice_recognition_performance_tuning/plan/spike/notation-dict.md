# S10 `notation-dict` — 表記の置換辞書

## 1. このセッションへの指示

- このセッションでやるのは **S10 だけ**。**優先度は低い。**
- **着手条件を確認する。** 課題①②に関わる他の spike（S1〜S9 のうち実施対象のもの）が片付いてから着手する。片付いていなければ、**実施せずに終わる。**
- これは**表記を自分の書き方に寄せる**ための施策である。**消えた英語を取り戻す用途ではない。** テキストからは復元できない。
- 意味を変える置換をしない。
- 結果は `notes/voice_recognition_performance_tuning/spike/notation-dict.md` に書く。**`main` にはマージしない。**

## 2. 背景

### 仮説

確定したテキストを表示する直前に、決まった規則で置換を当てると、読み返しやすさが上がる。

### 答える問い

- 実際に読み返しやすくなるか
- 意図せず壊れる事例が出ないか
- ニューラルネットを増やさずに、どこまで効くか

### 補足

`sherpa_onnx` には `HomophoneReplacerConfig`（`dictDir` / `lexicon` / `ruleFsts`）という設定があり、`OfflineRecognizerConfig` の `hr` に渡せる。ただし**この仕組みが日本語でそのまま使えるかは未確認**である。使えない場合は、**確定テキストに対する単純な置換**で十分に仮説は試せる。**どちらでやるかは、着手時に `~/.pub-cache/hosted/pub.dev/sherpa_onnx-1.13.8/lib/src/homophone_replacer_config.dart` と sherpa の公開資料を見て決める。**

## 3. 開始条件と依存

- ブランチ: `main` から `spike/voice_recognition_performance_tuning/notation-dict` を切り、`sherpa_onnx` を 1.13.8 にする
- **依存**: `spike/current-baseline.md`（音声と、いまの出力）
- **着手条件**: 課題①②の他の spike が片付いていること。片付いていなければ実施しない

## 4. 作業の分担

| 誰が | 何を |
|---|---|
| エージェント | ブランチ作成、置換の仕組みの用意、固定音声での実行、前後の比較、記録の下書き |
| **人** | **置換したい表記の提供**、出力の読み比べと良し悪しの判断 |
| 止まる条件 | 置換の規則をもらうところ。**何を置換すべきかはエージェントが決めない** |

## 5. エージェントが行う手順

1. ブランチを切り、`sherpa_onnx` を 1.13.8 にする。
2. 着手条件を確認する。**満たしていなければ終わる。**
3. **人に §6 を依頼して置換の規則をもらう。ここで止まる。**
4. 置換のやり方を決める（`HomophoneReplacerConfig` か、確定テキストへの単純な置換か）。**簡単に試せるほうを選ぶ。**
5. S3 の音声を流し、**置換の前と後の両方**をファイルに書き出す。
6. 前後を突き合わせ、**変わった事例と、意図せず壊れた事例の両方**を拾う。
7. 人に読み比べてもらう。

## 6. 人が行う手順

1. **置換したい表記を返す**

| 返してほしいもの | 形 |
|---|---|
| 置換の規則 | 「プッシュ通知 → push通知」のように、前と後で |
| なぜそうしたいか | 読み返しやすさ / 検索しやすさ など |

2. 出力の前後を読み、次を返す

| 返してほしいもの | 形 |
|---|---|
| 読み返しやすくなったか | 良い / 変わらない / 悪い |
| 壊れた事例 | 置換されるべきでない場所が変わってしまった例 |

## 7. 観察・記録の枠

`notes/voice_recognition_performance_tuning/spike/notation-dict.md` に写す表。

|---|---|---|---|
| 1 | | | |

### 壊れた事例（**必ず探して書く**）

| # | 置換前 | 置換後 | 何が壊れたか |
|---|---|---|---|
| 1 | | | |

読み返しやすさは数値にしにくいので、**人の判断をそのまま引用で残す**。

## 8. やらないこと

- 意味を変える同音語の一括置換
- 消えた英語を復元しようとすること
- 置換の規則を管理する画面の実装
- モデル・区切り設定・ライブラリの変更

## 9. 完了条件と、次へ渡すもの

**完了条件**: 置換の前後の違いと、**壊れた事例（または壊れなかったという事実）**が記録に残っていること。

**次へ渡すもの**: `spike/notation-dict.md` のみ。**コードはマージしない。**
