# S9 `hotwords` — 用語登録が効くかを見る

## 1. このセッションへの指示

- このセッションでやるのは **S9 だけ**。
- **まず実施条件を確認する。** S7 `qwen3` が RAM・熱・詰まりで落ちていたら、**この spike は実施しない。** 理由を記録に書いて終わる。
- 変えるのは**用語を渡すかどうかだけ**。モデルも設定も S7 のままにする。
- **「効いた」だけを書かない。** 無関係な語が増える方向に働いていないかを、必ず対照で見る。
- 用語を登録する画面は作らない。
- 結果は `notes/voice_recognition_performance_tuning/spike/hotwords.md` に書く。**`main` にはマージしない。**

## 2. 背景

### 仮説

固有名詞・専門用語を事前に渡すと、その語の誤りが減る。

### 前提（`research/opus_repropose_v3.md` §2-3）

`sherpa_onnx` の現行版で用語登録が動く経路を持つのは **Qwen3-ASR だけ**である。Qwen3 では用語がプロンプトに注入される仕組みで、他のモデルで使う一般的な仕組みとは別物である。現行モデル（CTC）にも SenseVoice にも経路が無い。

### 答える問い

- 渡した語は、実際に正しく出るようになるか
- **用語を含まない音声で、無関係な語が挿入されるようになっていないか**
- 処理時間は増えるか

## 3. 開始条件と依存

- ブランチ: **S7 `qwen3` のブランチから枝を切る**（同じモデル・同じ設定を土台にするため）。名前は `spike/voice_recognition_performance_tuning/hotwords`
- **依存**: `spike/qwen3.md` があり、**条件外で落ちていないこと**
  - 落ちていたら、このセッションは**実施しない**
  - 記録が無ければ止める
- S3 の音声を使う

## 4. 作業の分担

| 誰が | 何を |
|---|---|
| エージェント | 実施条件の判定、ブランチ作成、用語の受け渡し、対照を含む実行、突き合わせ、記録の下書き |
| **人** | **登録する用語の提供**（自分がよく話す固有名詞・専門用語）、実機への再インストール、出力の読み比べ |
| 止まる条件 | 用語リストをもらうところ。**何を登録すべきかはエージェントが決めない** |

## 5. エージェントが行う手順

1. **最初に実施条件を判定する。** `spike/qwen3.md` を読み、条件外で落ちていれば**ここで終わる**。
2. S7 のブランチから枝を切る。
3. **人に §6 を依頼して用語リストをもらう。ここで止まる。**
4. 用語を `OfflineQwen3AsrModelConfig` の `hotwords` に渡す。書式（区切り文字・長さの上限）は、**着手時に `~/.pub-cache/hosted/pub.dev/sherpa_onnx-1.13.8/lib/src/offline_recognizer.dart` と sherpa の公開資料で確認する。想像で書かない。**
5. **3通りを同じ音声で流す。**
   - **A: 用語なし**（S7 の結果をそのまま使ってよい）
   - **B: 用語あり**
   - **C: 用語あり × 用語を含まない音声**（無関係な語が挿入されないかを見る対照）
6. 出力をファイルに書き出し、突き合わせる。
7. **処理時間の差も記録する。** 追加の計算を「ほぼ無料」と決めつけない。
8. 用語の数を変えて試せるなら、少数と多数の両方を見る（多いほど効くとは限らない）。

## 6. 人が行う手順

1. **登録したい用語を返す。** 自分がよく話すもので、いま間違われているものを優先する

| 返してほしいもの | 形 |
|---|---|
| 用語のリスト | 10〜30語程度。人名・社名・製品名・専門用語など |
| その語が今どう間違われるか | 分かる範囲で。「〇〇 → ✕✕ になる」 |

2. 実機への再インストールの承認と操作
3. 出力を読み、次を返す

| 返してほしいもの | 形 |
|---|---|
| 渡した語は正しく出たか | 語ごとに |
| **言っていない語が出てきたか** | 出た場合、その語と前後の文 |
| 文全体の自然さ | 用語は合っているが文が不自然になっていないか |

## 8. やらないこと

- モデル・区切り設定・ライブラリの変更

- 副作用の確認を省くこと

**完了条件**: 渡した語が直ったかと、**無関係な語が増えていないか**の両方が記録に残っていること。

**次へ渡すもの**: `spike/hotwords.md` のみ。**コードはマージしない。**
