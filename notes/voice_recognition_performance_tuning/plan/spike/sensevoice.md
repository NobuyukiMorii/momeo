# S6 `sensevoice` — SenseVoice Small に差し替えて比べる

## 1. このセッションへの指示

- このセッションでやるのは **S6 だけ**。他のモデル（Qwen3・Nemotron）には進まない。
- 変えるのは**認識モデルだけ**。ライブラリは 1.13.8 のまま、区切り設定は S5 で決まった値のままにする。
- **配布の作り込みをしない。** Play Asset Delivery も準備ゲートも触らない。**モデルを端末の固定パスに置いて読むだけ**でよい。
- S3 の音声と、S4 の記録が**必須**。無ければ**進まずに止まる**。
- 「軽い」「多言語」だけを理由に良い結果と書かない。**最優先は日本語**である。
- **人の手数を増やす作りにしない**（`master.md` §1 の原則）。とくに次をさせない。
  - **モデルの取得と配置を人の作業にしない。** ダウンロードから端末への配置までを**スクリプト1本**にし、人は1コマンド叩くだけにする
  - **全件の出力を読ませない。** 現行との差分が出た行だけを見せる
  - **設定を変えるたびに再インストールさせない。** `language` の自動と `ja` 固定は**画面から切り替えられるようにし、1回のインストールで両方試す**
- **英語混じりは「表記が定まるか」で見る。** S3 で、現行モデルは「英語を出せない」のではなく「**表記が定まらない**」と分かった（`I think` が8通り、同じ語が実行ごとに変わる）。**同じ音声を2回流し、候補自身の出力が安定しているかも確かめる。**
- 結果は `notes/voice_recognition_performance_tuning/spike/sensevoice.md` に書く。**`main` にはマージしない。**

## 2. 背景

### 仮説

日本語・英語・中国語を1モデルで扱え（課題②③）、**日本語も現行に並ぶ**（課題①）。

**この仮説は棄却されうる。** 開発元の論文では SenseVoice-Small の日本語は 11.96 で、Whisper-large-v3（10.34）より悪いと公表されている。sherpa で配布されているのは Small のみで、良い Large は無い（`research/opus_repropose_v3.md` §1-C-2）。テストセットが違うので現行と直接は比べられないが、**日本語で現行に並ぶ根拠は無い状態で試す**。

### 答える問い

- 日本語は現行と比べてどうか
- **日本語に混ざる英語の表記は定まるか**（現行は定まらない。S3 §5）
- 英語・普通話は実用になるか（**現行は崩壊する**。34.7 秒が `そうニ`、普通話は漢字が出ない）
- 常駐RAM・異常終了・処理時間はどうか

## 3. 開始条件と依存

- ブランチ: **S4 `lib-update` のブランチから枝を切る**（足場と 1.13.8 が揃っているため）。名前は `spike/voice_recognition_performance_tuning/sensevoice`。**足場を作り直さない**（`master.md` §1）
- **依存**
  - `spike/current-baseline.md` と、**端末内の音声・`answers.tsv`**（比較の基準。正本は端末。`.dev_models/spike_audio/` はバックアップで、消えていれば `scripts/place_android_spike_audio.sh` で戻す）
  - `spike/lib-update.md`（土台の版を揃えるため）
  - **S4 の「丸ごと」経路の結果 TSV**（比較の基準。**録音時の結果を基準にしない**。S3 §6.1）
  - S5 を実施済みなら、そこで決まった区切り設定に合わせる
  - **欠けていたら、このセッションはここで止める**
- 前提: **Android 実機**（`master.md` §1）
- **S1 `power-triage` の結果を先に読むこと。** ASR が電力の主因だったなら、この spike の重要度が上がる（軽い候補だから）

## 4. 作業の分担

| 誰が | 何を |
|---|---|
| エージェント | 枝の作成、**モデル取得・配置スクリプトの用意**、認識器の設定の差し替え、固定音声での実行、現行との突き合わせ、記録の下書き |

## 5. エージェントが行う手順

1. S4 のブランチから枝を切る（`sherpa_onnx` は 1.13.8 のまま）。
2. S3・S4 の記録と、端末内の音声・`answers.tsv` があることを確認する。**無ければ止める。**
3. 足場（固定 wav を流す dev 経路）はブランチに入っている。**作り直さない。**
4. **モデルの取得と配置をスクリプト1本にする。** 対象は sherpa-onnx が配布する `sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2024-07-17`。
   - **2024-07 版を使う。** 2025-09 版は句読点に対応しないため、この spike では使わない
   - 中身は単一の `model.int8.onnx` と `tokens.txt`
   - **ダウンロードから端末への配置まで、人が1コマンド叩けば終わる形にする。** 既存の `scripts/download_nemo_model.sh`（取得）と `scripts/lib/spike_device.sh`（`/data/local/tmp` 経由 → `run-as jp.momeo` コピー）の流儀に合わせ、**新しい配布経路は作らない**
   - 手元の置き先は `.dev_models/`（`.gitignore` 済み）。端末側は `getApplicationSupportDirectory()` 配下の **spike 用サブフォルダ**
   - **展開後の容量と空き容量の確認もスクリプトの中で行う。** 人に計算させない
   - **`SttModelProvisioner` 本体は変更しない。** spike の dev 経路の中で固定パスを直接読む
5. **認識器の設定を差し替える。** `lib/stt/stt_audio_worker.dart` の `_AudioEngine._createRecognizer` は現在 `OfflineModelConfig(nemoCtc: OfflineNemoEncDecCtcModelConfig(model: ...), tokens: ...)` を組んでいる。これを SenseVoice 用に置き換える。
   - 使う設定クラスは `OfflineSenseVoiceModelConfig`。フィールドは `model` / `language` / `useInverseTextNormalization`
   - `language` は空文字が自動判定。明示するなら `ja` / `en` / `zh` など
   - **句読点を出すには `useInverseTextNormalization` を有効にする**
   - **`language` を「自動」と「`ja` 固定」の両方で試す。** どちらが良いかは測って決める。**画面から切り替えられるようにし、再インストールを繰り返させない**
   - 具体的なフィールド名と既定値は、着手時に `~/.pub-cache/hosted/pub.dev/sherpa_onnx-1.13.8/lib/src/offline_recognizer.dart` を開いて確認する。**想像で書かない**
6. **人に §6 を依頼する。ここで止まる。**
7. モデルが端末に置かれたら、S3 と同じ音声を同じ経路で流す。区分（日本語のみ / 日英混在 / 英語 / 普通話 / 雑音）ごとに出力をファイルへ書き出す。区分は `answers.tsv` の `category` 列から取る。**人に振り分けさせない。**
8. **同じ音声を2回流す。** 候補自身の出力が実行ごとに変わるかを見る（現行は変わる。S3 §6.1）。
9. 現行の出力（S4 の「丸ごと」経路の結果）と**1件ずつ突き合わせる**。突き合わせは `file` 列で結合し、**差分が出た行だけを人に見せる**。**録音時の結果を基準にしない。**
10. 実行中の**常駐RAM の最大値・異常終了・1発話あたりの処理時間**も記録する。RAM は `adb shell dumpsys meminfo` で取り、**人に読み取らせない。**

## 6. 人が行う手順

1. **スクリプトを1つ実行する**（圧縮で 150MB 前後、展開後 228MB 程度をダウンロードし、端末へ置くところまで自動）
2. 実機への再インストールの承認と操作
3. **差分が出た行だけ**を渡されるので、それを読んで次を返す

| 返してほしいもの | 形 |
|---|---|
| 日本語の読み返しやすさ | 現行と比べて良い / 同じ / 悪い。**実際の出力を引用して** |
| 英語混じりの見え方 | 英字で出たか、カタカナか、消えたか。**同じ語で表記が揺れていないか** |
| 気になった誤り | 否定・数値・日時・人名の間違いは特に |

**全件を読む必要はない。** 現行と差が無かったものは渡されない。
**`最終判定用` の音声は未収録**（S3 の残タスク）。S5 で録り足されていなければ、調整用だけで判断したことを記録に書く。
