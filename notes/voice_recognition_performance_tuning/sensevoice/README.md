## 今回、特に持ち帰りたいこと

1. **ITN の on/off は、数字・句読点の見た目だけの比較ではない。** モデルに与える条件が変わるため、単語の認識も変わり得る。`1600年 → 16002年` のような誤りを調べる入口になる。[設定の説明](model-and-settings.md#itn)
2. **日本語の空白は、検索にも影響する。** `徳川 家康` と保存すると、現在の検索では `徳川家康` に一致しない。表示・保存文を変更せず、検索用の正規化だけを改善する余地がある。[空白の扱い](languages.md#spaces)
3. **`maxSpeechDuration=30` は厳密な30秒上限ではない。** また、VAD の60秒バッファは固定のメモリ上限ではない。長文での欠落や待ち時間を調べる際は、設定値ではなく実際の区間長を見る。[長い発話](app-best-practices.md#segmentation)
4. **`auto → ja` を既定値の改善策にしない。** momeo では比較済みで、日本語の利得がなく普通話を壊した。言語取り違えが疑われる新しい音声だけ、限定して再比較する。[言語指定](languages.md#language)
5. **新しい日付のモデルが汎用の改良版とは限らない。** sherpa の2025-09-09版は広東語の微調整版で、公式に句読点非対応とされる。[モデル選択](model-and-settings.md#variants)
6. **再始動直後の欠けは、モデル精度以外の確認点がある。** 現行は VAD を `clear()` で再利用するが、native の `reset()` とは消す状態が異なる。実害は未確認で、停止後の再開・録音watchdogによる再始動時の検証候補。[状態の扱い](app-best-practices.md#restart)

## 事実・提案の読み分け

- **現行コード**: 今の momeo に存在する設定や処理。
- **既存実測**: `../spike/` の記録。特に VAD の比較は旧 NeMo 上の結果である。
- **公式仕様・実装**: 出典の版で確認した挙動。FunASR の機能を、そのまま Dart で使えるとは扱わない。
- **利用者報告**: Issue 投稿者の環境での事例。一般的な不具合や momeo の原因と断定しない。
- **提案・未検証**: 次に試す仮説。改善を保証する設定値ではない。

採用そのものは [adopt-sensevoice.md](../decision/adopt-sensevoice.md)、実装完了の経緯は [next-steps.md](../decision/next-steps.md) が正本です。過去文書には実装前の記述も残っているため、現在値はコードから確認しました。既存の「まず使い切り、調整はそのあと」「採用前に大規模な測定ゲートを置かない」という判断を維持し、ここでは調査と任意の比較候補をまとめます。
