# スプラッシュシーケンス仕様

## 概要
このシーケンスは、**アプリ起動時に毎回表示される**単一の画面です。
複数の画面遷移ではなく、1つの画面内でアプリのコンセプトを伝えるテキストがアニメーションしながら切り替わります。

表示するテキストは外から渡す配列で制御します。

- **初回起動時**: 4行のコピーを順番に表示し、最後に録音ボタンが押される演出を出す
- **2回目以降**: 文字は出さず、録音ボタンが押される演出だけを出して次のフローへ進む

## 録音ボタンの演出
アプリアイコンと同じ「輪＋黒丸」を画面中央に出し、黒丸がひとりでに押されたように一度沈んで戻ります。「アプリを開く＝録音ボタンを押す」ことを伝えるための演出です。

- 少し待つ → 黒丸が 86% まで沈む（100ms）→ 弾むように戻る
- 輪は動かさない
- 表示時間はテキスト1つ分と同じ 1500ms
- コピーから録音ボタンへはフェード（300ms）で切り替える

### OS の起動画面からの引き継ぎ
OS の起動画面（iOS の LaunchScreen・Android の起動画面）にも、同じ大きさ（外径 120pt / 120dp）・同じ位置（画面中央）の録音ボタンを出します。Flutter のボタンはフェードインせず最初から表示し、OS の画面からそのまま入れ替わって見えるようにします。

- 初回起動かどうかを読み終えるまで Flutter の最初の描画を止め、その間は OS の起動画面を出したままにする
- Android は Flutter が最初の画面を描き終えるまで起動画面を残し、外すときもフェードさせない
- iOS の起動画面の画像は `ios/Runner/Assets.xcassets/LaunchImage.imageset`、Android は `android/app/src/main/res/drawable/splash_record_button.xml`

## アニメーションの挙動
- 最初のテキストは初期状態から画面左下に表示されます。
- 一定時間経過後、次のテキストが右からスライドインし、所定の位置で停止します。
- 同時に、現在のテキストは左に移動しながら退場します。
- この遷移が設定されたテキストの数だけ繰り返されます。

## 表示テキスト
初回起動時に表示するテキスト項目は以下の通りです。4行のコピーで世界観を伝え、最後に録音ボタンの演出で受けます。
1. `時の流れの中で生まれ`
2. `薄れ消えゆく思考を`
3. `そっと残すために`
4. `ただ話しかけるだけ`

見出しは32pxで、左右余白24ptを引くと1行に入るのは10文字までです。各行は10文字以内に収めます（超えると2行目に1文字だけ残る折り返しが起きます）。

## 設定可能な項目
この画面は柔軟な設定が可能なテキストシーケンスとして実装されています。以下の項目は固定せず、変更可能にします。
- テキスト項目の数
- 各テキストの内容
- アニメーションの持続時間
- 各テキストの停止時間
