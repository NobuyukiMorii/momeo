# リスニング画面の録音設定パネル仕様

## 概要

リスニング画面の上端に、いつ録音するかを示す状態行を常に表示します。状態行を押すと、その下に選択肢のカードが下りてきて、バックグラウンド録音の有効・無効を切り替えられます。

この文書が扱うのは画面の UI と設定値までです。バックグラウンドで実際に録音を続けるための実装（フォアグラウンドサービス、常駐通知、iOS の録音中表示）は `notes/background_recording/` が扱います。

## 画面での位置づけ

- パネルは画面の上端（安全領域を含む）に貼り付きます。閉じているときは状態行1行だけが見えていて、その下に検索フィールドが続きます。
- 開いたときの選択肢のカードは、検索フィールドやボイスカードの上に覆いかぶさります。下にあるものを押し下げはしません。
- 画面の上端とパネルの左右には、常に線を引きます。開いている間は、下の線を開き具合に合わせて少しずつ濃くし、下の角も少しずつ丸めます。
- 状態行の高さは、端末の文字サイズの設定で文言が大きくなったぶんだけ伸びます。

## 状態行（常に見えている部分）

| 位置 | 内容 |
|---|---|
| 左 | 録音の範囲を示すドット |
| 中央 | 今選んでいる選択肢のタイトル |
| 右 | 開いているかを示す山形（開くと半回転して上を向く） |

- ドットは、ほかのアプリを使っていても録音する設定なら**赤**（強い注意 `caution`）、このアプリを使っている間だけ録音する設定なら**黄**（弱い注意 `notice`）です。
- どちらの設定でも録音は続いているため、ドットは常に点滅します。
- 文言は1行に収め、入りきらない場合は末尾を省略します。

## 開閉

| 操作 | 結果 |
|---|---|
| 状態行を押す | 開いていなければ開き、開いていれば閉じる |
| パネルの外を触る | 閉じる。触り方はそのまま下のボイスカードや選択バーへ届く |
| 選択肢のカードの周りの余白を押す | 閉じる |
| パネルを勢いよく上へ払う | 閉じる（下へ払っても開かない） |

- 開き閉じは 250ms で動きます。
- パネルの外を触って閉じるとき、その触り方でボイスカードの選択、選択バーの削除・コピー・解除、一覧のスクロールもそのまま成立します。
- 開いている間も録音と文字化は続きます。
- 起動のたびに閉じた状態から始めます。

## 選択肢 — バックグラウンド録音

いつ録音するかを、横に並んだ2枚の選択肢カードで選びます。それぞれドット・タイトル・説明文を持ち、選んでいるほうは枠線が太くなり、ドットも少し大きくなります。2枚の高さは中身の多いほうに揃えます。

| | タイトル | 説明文 |
|---|---|---|
| 無効（左） | このアプリを使ってる時だけ録音 | ほかのアプリを使っている間やホーム画面では録音を止めます。 |
| 有効（右） | ほかのアプリを使っていても録音 | ほかのアプリを使っている間やホーム画面でも録音し続けます。 |

- 初期値は無効です。設定は端末に保存し、アプリを再起動しても前回の状態を保ちます。
- 無効から有効にするとき、まだ一度も有効にしていない間は、切り替えのたびに開示と同意のダイアログを表示します。一度有効にしたあとは表示しません。ただし Android では、一度有効にしたあとでも通知の許可が無い間は表示します（ダイアログが許可への導線を兼ねるため）。
- 有効から無効に戻すときは確認しません。

### 開示と同意のダイアログ

```text
ほかのアプリを使っていても録音しますか？

ほかのアプリを使っている間や画面を消している間も、
マイクで音声を録り続けます。

録音した音声と文字起こしはこの端末の中だけに保存され、
外部に送信されることはありません。

（Android のみ、ここに通知についての一文が入る。下記）

この設定はいつでも解除できます。

     ［キャンセル］［有効にする］
```

Android では、通知の許可の状態に応じた一文を本文に挟みます。

| 通知の許可 | 挟む一文 |
|---|---|
| ある | 録音中は、録音していることを通知でお知らせし続けます。 |
| ない | ほかのアプリを使っている時にも録音していることをお知らせし続けるため、通知の許可が必要です。「有効にする」を押すと端末の設定が開くので、momeo の通知を許可してください。 |

| 選択 | 結果 |
|---|---|
| キャンセル | 無効のまま。選択肢も無効の表示のまま |
| 有効にする（iOS、または Android で通知の許可がある） | 有効になり、状態行のドットが赤に変わる |
| 有効にする（Android で通知の許可が無い） | 端末の設定が開く。momeo の通知を許可して戻ると、自動で有効になってダイアログが閉じる。許可せずに戻るとダイアログはそのまま |

- ダイアログの外側をタップしても閉じません。どちらかのボタンを押してもらい、同意を能動的な操作で取ります。
- ダイアログを開いたまま端末の設定から戻ってくると、通知の許可を確認し直し、本文の一文と「有効にする」の挙動が切り替わります。
- Android だけ通知の許可を条件にするのは、バックグラウンド録音中の常駐通知が Play の実質的な要件のためです。iOS に許可の条件はありません（→ `notes/background_recording/impl/phase1/step03_notification_permission_gate.md`）。
