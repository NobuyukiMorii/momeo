# リスニングフロー仕様

## 概要
権限許可後、アプリは自動的にリスニング状態で開始されます。ユーザーは録音ボタンを探すことなく話し始めることができます。

音声認識はオンデバイス STT（`sherpa_onnx` + SenseVoice Small）で行います。OS の音声認識サービスには依存せず、モデルが端末にあれば実行は完全オフラインです。

> リスニング画面に入る前提として、文字化エンジンの準備完了を待つ「準備ゲート」があります（`notes/specs/preparation_gate.md`）。リスニング画面に到達した時点でエンジンは常に使用可能です。

## 画面構成

メモ一覧は日記のように、古いメモが上・新しいメモが下に、1続きの文章として並びます。メモ1件を「ブロック」と呼び、ブロックとブロックの間は少し空けます。一覧は画面下端に固定され、新しいメモは一番下に現れて、既存のメモを上へ押し上げます。メモが少ないうちは一覧全体が画面下部に寄ります。

```text
 お婆ちゃんの家に行った。元気そうで   ◯
 よかった。                           │
                                      │
 耳と記憶は弱くなってて心配。         ◯
 京都水族館に行ってソフトクリーム     │
 を食べた。                           │
```

| 要素 | 見た目 |
|---|---|
| 本文 | 文字サイズ 18（端末の文字サイズの設定に従う）、行の高さは文字の約2倍、ブロックの間は 24。書体は iOS がヒラギノ、Android が Noto Sans JP（アプリに同梱） |
| 右の縦線と丸 | 一覧の右寄りに1本の縦線を引き、各ブロックの始まりに丸を置く。丸は、上のブロックの最後の行の文字と、そのブロックの1行目の文字のちょうど間に来る |
| 日時 | ブロックごとには出さない。スクロール中だけ背景に出す（後述「スクロールつまみと日付」） |

- 一覧は画面の下端まで広がります。スクロールの途中では本文がホームインジケーター（Android はナビゲーションバー）の下を通り抜けて流れ、一番下までスクロールしたときだけ、最新の行がその上に離れて止まります。
- 開いたときは一番下（最新）を見せます。一番下を見ている間は、新しいメモが来ても、一覧の高さが変わっても（選択バーの出入りなど）、一番下のまま保ちます。
- 一覧は OS の部品（iOS は `UITextView`、Android は `TextView`）で描き、メモ全件を1つの文書として持ちます。そのため、OS 標準の文字選択をメモをまたいで使えます。

## メモのまとめ方

ひと続きの話は1つのメモに、間が空いたら別のメモに分けます。

| 状況 | 結果 |
|---|---|
| 最後に書き足してから 10秒以内に、次の発話が始まる | 同じメモの末尾に書き足す |
| 10秒以上たってから、次の発話が始まる | 新しいメモを起こす |
| 録音が止まった（バックグラウンドへ移ったときなど） | 次の発話は新しいメモを起こす |
| 書き足し先のメモが削除された | 次の発話は新しいメモを起こす |

- 書き足すときは、前の本文と新しい発話の間に何も挟まず、そのままつなげます。
- 日付が変わっても、10秒以内なら同じメモに書き足します（夜中の0時をまたいで、話が2つのメモに割れないようにするため）。
- メモの作成日時は、そのメモの最初の発話が始まった時刻です。

## メモの選択

メモは右の丸で選べます。縦線と丸の帯（一覧の右端）をタップすると、その高さより上で一番近い丸のメモの選択・選択解除が切り替わります。選択したメモへの操作（削除・コピー・解除）は、画面下端の選択バーで行います（`notes/specs/listening_selection_bar.md`）。

```text
丸をタップ → 本文が太字になり、丸が大きく、そのブロックの線が太くなる
↓
画面下端に選択バーがせり上がり、選択件数と操作が並ぶ
↓
選択が 0 件になると、選択バーは下へ引っ込む
```

- 選択中のメモの丸をもう一度タップすると選択が解除され、元の太さに戻ります。
- 続けて並んだメモを選ぶと、太い線が1本につながります。
- 本文をタップしても、メモの選択は切り替わりません（本文は文字選択に使います）。
- 選択状態はアプリ全体で1つです。選択バーの「解除」を押すと、一覧側の選択もすべて外れます。
- コピーは選択中のメモの本文を時系列順に連結したもので、古い発言が上・新しい発言が下になるように改行でつなぎます（一覧の表示順と同じ）。
- コピーするのは本文のみで、日時は含めません（他アプリへ貼るときに日時が混ざらないようにするため）。
- タイピング演出の途中で選択・コピーされた場合も、表示途中の文字列ではなく確定テキスト全文が対象です。

## 文字選択

本文の文字は、OS 標準の操作で選べます。メモをまたいで選ぶこともできます。

| 操作 | 結果 |
|---|---|
| 長押し・ダブルタップ | 語を選ぶ（つまみ・選択色・拡大表示・メニューは OS 標準） |
| つまみのドラッグ | 範囲を広げる・縮める。メモをまたいでよい |
| メニューの「コピー」 | 選んだ範囲に掛かる各メモの部分を、空行1つでつないでクリップボードへ入れる。文字選択は残す |
| メニューの「すべて選択」 | 一覧の全件を選ぶ（画面の外のメモも含む）。すでに全件を選んでいるときは出さない（iOS） |
| 選択色が付いているところを1回タップ | 文字選択を外す（文字の無いブロック間の余白でもよい） |
| 録音設定パネルに触れる | 文字選択を外す |

- 選択範囲の両端は、掛かっているメモの本文の端までに収めます。ブロック間の余白や、本文が空のメモだけを選んだ状態にはしません。
- メニューの言語は、端末の言語（日本語・英語）に従います。
- 文字選択と、丸によるメモの選択は別の状態です。丸を押しても選択バーを使っても、文字選択は外れません。
- 打ち出し中のメモは、打ち終わるまで文字選択・コピー・すべて選択の対象にしません。

選んでいる間も録音は続きます。その間に一覧が変わっても、選択は保ちます。

| 選んでいる間に起きること | どうなるか |
|---|---|
| 一番下に新しいメモが増える | 選択はそのまま。一番下へは移動しない |
| 選んでいるメモに書き足される | 選んだ時点の本文のまま出す。書き足した分は、選択を外すと出る |
| 選んでいるメモが削除される | 選択を外す |

## スクロールつまみと日付

右の縦線の上に横棒のつまみを重ね、OS 標準のスクロールバーの代わりにします。

| 項目 | 動き |
|---|---|
| つまみの位置 | 一番上（最古）までさかのぼると上端（一番上の丸の高さ）、一番下（最新）では下端（ホームインジケーター・ナビゲーションバーの上） |
| 出すとき | いつも出す。スクロールできないほど短い一覧では出さない |
| ドラッグ | 指を置いてそのまま動かせば掴める（長押しは要らない）。細い横棒でも掴めるよう、当たり判定は見た目より上下に広げる |
| 動かさずに離したとき | つまみの下の線・丸のタップとして扱う（メモの選択が切り替わる） |

指やつまみでスクロールしている間だけ、つまみの高さにあるメモの日付を、本文の後ろに薄く大きく出します。

```text
 お婆ちゃんの家に行った。元気そうで   ◯
      2026.09.26                     ─┼─  ← つまみ
 耳と記憶は弱くなってて心配。         ◯
```

| 項目 | 動き |
|---|---|
| 出す日付 | つまみの高さより上で、一番近い丸を持つメモの作成日（時刻は出さない） |
| 出すとき | 指やつまみでスクロールしている間だけ。止まって 0.6秒たつと消える。新しいメモが増えて一番下へ自動で移るときは出さない |
| 現れ方・消え方 | 0.2秒かけてふわっと |
| 見た目 | 筆記体（Dancing Script）、文字サイズ 48、本文の色の 10%。高さはつまみにそろえ、左右は本文の表示領域の中央。狭い画面では縮めて1行に収める |
| 触ったとき | 反応しない（下の本文に届く） |

## 認識パイプライン

リスニング画面に入ると、録音 → 区切り → 文字化のパイプライン（`lib/stt/stt_listening_pipeline.dart`）が自動で開始されます。

```text
🎤 record でマイクを連続キャプチャ（PCM16 / 16kHz / モノラル）
  ↓ Float32 に変換し、512サンプル窓ごとに供給
sherpa 内蔵 Silero VAD（発話の開始〜終了を検出）
  ↓ 1発話ぶんの音声チャンク
sherpa-onnx OfflineRecognizer（SenseVoice Small）でバッチ文字化
  ↓
確定テキスト → メモとして保存・表示
```

- 文字化エンジンはアプリ全体で1つだけ保持される共有エンジン（`sttEngineProvider`）を借りて使います。
- 画面を離れるときはパイプラインを停止し、VAD 内に残った末尾の発話を押し出して文字化してから破棄します。
- パイプラインは確定テキスト（`onText`）に加えて、VAD の「発話中かどうか」の変化を `onSpeechActiveChanged` で画面へ通知します。発話中の「.」はこの通知で駆動します。

## バックグラウンドでの挙動

アプリがバックグラウンドへ移ったときの挙動は、「バックグラウンド録音」設定（→ `notes/specs/listening_recording_settings_panel.md`）で変わります。

| 設定 | バックグラウンド遷移 | フォアグラウンド復帰 |
|---|---|---|
| 無効（初期値） | 録音を停止する（VAD に残った末尾の発話は文字化して保存する） | 録音を再開する |
| 有効 | 録音・文字化を続ける。確定したメモは保存され、復帰後の一覧に反映される | 表示が戻るだけ（録音は続いたまま） |

有効時にバックグラウンドで録音を続けるための仕組みは OS ごとに異なります。Android は microphone 型のフォアグラウンドサービスと常駐通知（「バックグラウンド録音を停止」ボタン付き。押すと設定ごと無効になる）、iOS は `UIBackgroundModes`（audio）の宣言と、録音中を示す Live Activity（書き留めた件数を表示）です。実装と規約の背景は `notes/background_recording/` が扱います。

## 話している気配

「今アプリはあなたの発話を認識していますよ」という気配を、本文が入る場所に「.」を増やすことで表現します。判定は音量ではなく Silero VAD の発話検知（人の声らしさ）に基づくため、環境音では基本的に反応しません。

```text
 耳と記憶は弱くなってて心配。......    ◯      ← 同じメモに書き足すとき
```

```text
 耳と記憶は弱くなってて心配。         ◯
                                      │
 ......                               │      ← 新しいメモを起こすとき（丸は出さない）
```

| 項目 | 動き |
|---|---|
| 出す間 | 発話開始を検出してから（話し始めから約 minSpeechDuration = 1秒 後）、結果が届く（本文が現れる、または空の結果で終わる）まで |
| 増え方 | 0.5秒ごとに1つ増え、10個で0個に戻る。行に収まらないときは、収まる数で戻る |
| 出す場所 | 同じメモに書き足すときは、最新のメモの最後の文字の後ろ。新しいメモのときは、次のメモの1行目（その間は、ブロック間の余白と1行分の高さを一覧の下に空けておく） |
| 場所が決まるとき | 話し始めたとき。話している途中では動かない |
| 出さないとき | 直前の発話を打ち出している間（打ち終わってから出す）、文字選択中 |
| 見た目 | 本文と同じ文字・同じ色 |
| コピー | 本文ではないので、コピーや「すべて選択」の対象にならない |

30秒上限での強制区切り（ユーザーがまだ話し続けている）のときは、メモが打ち出されたあと、その続きに「.」が再び出ます。

> 文字化は発話終了後に1発話ぶんを一括で行うため、認識途中のテキスト（部分結果）は存在しません。そのため「.」は文字を表さず、「アプリが発話を認識している」という気配だけを伝えます。

## 確定演出

確定したメモは、本文が1文字ずつ素早く打ち出されます（最大1.8秒以内に打ち終わる）。この演出は直前に確定した1件だけに付き、書き足したときは書き足した分から打ち出します。起動時や画面の再表示では、打ち出さずに全文を出します。

## メモ確定条件

**VAD の発話終了検出を確定トリガーとする。**

Silero VAD の区切り設定（`stt_audio_worker.dart` の定数）:

| 項目 | 値 | 意味 |
|---|---|---|
| `minSilenceDuration` | 3秒 | 無音がこの時間続いたら発話終了とみなす（＝メモ確定の合図）。話の途中で少し考えて黙っても切れないようにする |
| `minSpeechDuration` | 1秒 | これより短い音は発話とみなさない（物音から出る「Yeah.」のような1語だけのメモを減らす） |
| `maxSpeechDuration` | 30秒 | 1発話の上限。超えたら強制的に区切る |

## 確定テキストの採用ルール

- 確定テキストは、発話チャンク全体を一括で文字化した結果をそのまま採用します。部分結果と最終結果の使い分けは存在しません。
- **空文字は保存しない**: 無音・雑音による空の認識結果は、保存前に弾きます（前後の空白を除去した上で空なら破棄）。

## 確定フロー

```text
ユーザーが話す
↓
【 確定条件 】
 └─ 無音が 3秒 続き、VAD が発話終了を検出する
↓
1発話ぶんの音声チャンクを sherpa-onnx（SenseVoice Small）で文字化する（実測 100〜300ms）
↓
確定テキストをメモとして保存し、一覧の末尾（画面の一番下）に表示する（10秒以内なら、最新のメモに書き足す）
↓
録音は止まらず連続キャプチャのまま、次の発話を待ち受ける
```

発話が確定しても認識セッションを再開する必要はなく、録音は画面にいる間ずっと連続しています。

区切りと転写は音声 isolate で動きます。転写の最中に届いた録音チャンクは待ち行列に積まれるため、長い転写中に喋った音声も取りこぼしません。画面の描画も転写に影響されません。

## 今後の検証項目

- 無音 3秒 の区切りと、書き足しの 10秒が、実際の利用感として心地よいかどうかは、実機検証を通じて調整します。
