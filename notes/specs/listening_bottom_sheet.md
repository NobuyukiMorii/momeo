# リスニング画面のボトムシート仕様

## 概要

リスニング画面の下端に、つまみ付きのボトムシートを常設します。閉じているときも上端の帯がわずかに見えていて、「バックグラウンド録音の状態」と「選択中のカード枚数」を伝えます。上に開くとブラックボードでの確認・操作ができ、帯の左の状態表示をタップするとバックグラウンド録音の選択肢が現れます。

この文書が扱うのは画面の UI と設定値までです。バックグラウンドで実際に録音を続けるための実装（フォアグラウンドサービス、常駐通知、iOS の録音中表示）は `notes/background_recording/` が扱います。

## 画面での位置づけ

- シートはメモ一覧に重なりません。画面の下端から順にシートが領域を取り、その境界より上がメモ一覧、下がシートです。閉じているときは帯だけが領域を取ります。
- 帯は安全領域（ホームインジケーター）より上に置きます。スワイプを受けるため、安全領域には掛けません。
- メモ一覧の下端余白はシートの高さに追従します。シートを開くとカードは同じ速さで上へ押し上げられ、指で途中まで引き上げている間も追従します。
- メモ一覧は下端に固定されているため、シートを開いても一番下（＝最新）のカードはシートの上端に接した位置で見え続けます。
- 選択中のカードに対するコピー操作は、シート内のブラックボードに触れて行います。

## 帯（常に見えている部分）

閉じているときも開いているときも表示され続ける、シートの上端です。

| 位置 | 内容 |
|---|---|
| 中央 | つまみ（ハンドル） |
| 左 | バックグラウンド録音の状態を示すドットと文言、選択肢の開閉を示す矢印 |
| 右 | 選択中のカード枚数と、選択を解除する操作 |

- ドットは、他のアプリを使っている間も録音する状態なら**赤**（強い注意 `caution`）、このアプリを使っている間だけ録音する状態なら**黄**（弱い注意 `notice`）です。
- どちらの状態でも録音は続いているため、ドットは常に点滅します。
- ドットの横に状態の文言を添えます。有効なら「ほかのアプリを使っていても録音」、無効なら「このアプリを使っている時だけ録音」です。
- 文言の右の矢印は、シート上側の選択肢が開いているかどうかを示します。左側のまとまり（ドット・文言・矢印）のタップで選択肢を出し入れします（→「開閉」）。
- 右側は「◯件の選択を解除」と表示し、タップすると選択がすべて外れます。メモ自体は残ります。
- 右側は 1 枚以上選んでいるときだけ表示し、0 枚のときは何も出しません。

## 開閉

| 操作 | 結果 |
|---|---|
| シートを上へスワイプ | 開く |
| シートを下へスワイプ | 閉じる（開いていた選択肢も畳む） |
| 帯の左の状態表示をタップ | 選択肢の表示を切り替えて、シートを開く |

- タップでシートが開くのは帯の左の状態表示だけです。つまみや帯の余白をタップしても開きません。メモ一覧を触っている指が帯に触れただけで開いてしまうのを避けます。
- 検索フィールドへの入力が始まったときは、アニメーションを挟まずその場で畳みます。開いていた選択肢も畳みます。
- スワイプ中、シートは指に追従します。離したときは、速さが十分ならその向きへ、そうでなければ近いほうへ落ち着きます。
- 開いたときの高さは、中身の量に関わらず常に同じです。
- 開いている間もメモ一覧は明るいままで、カードをタップして選択でき、一覧をスクロールすることもできます。
- 開いている間も録音と文字化は続きます。確定したメモは一覧の末尾に追加され、シートの上で見えます。

## シート上側 — バックグラウンド録音

- いつ録音するかを、横に並んだ2枚の選択肢カードで選びます。それぞれタイトルと説明文を持ち、選んでいる方の枠線が太くなります。

| | タイトル | 説明文 |
|---|---|---|
| 無効（左） | このアプリを使っている時だけ録音 | アプリがバックグラウンドに移ると録音を止め、フォアグラウンドに戻ると再開します。 |
| 有効（右） | ほかのアプリを使っていても録音 | ほかのアプリを使っている間や画面を消している間も、マイクで音声を録り続けます。アプリを終了すると止まります。 |

- 選択肢は帯の左の状態表示をタップしたときだけ表示し、シートを閉じると畳みます。起動のたびに畳んだ状態から始めます。
- 初期値は無効です。設定は端末に保存し、アプリを再起動しても前回の状態を保ちます。
- 無効から有効にするとき、まだ一度も有効にしていない間は、切り替えのたびに開示と同意のダイアログを表示します。一度有効にしたあとは表示しません。ただし Android では、一度有効にしたあとでも通知の許可が無い間は表示します（ダイアログが許可への導線を兼ねるため）。
- 有効から無効に戻すときは確認しません。

### 開示と同意のダイアログ

```text
ほかのアプリを使っていても録音しますか？

ほかのアプリを使っている間や画面を消している間も、
マイクで音声を録り続けます。

録音した音声と文字起こしはこの端末の中だけに保存され、
外部に送信されることはありません。

（Android のみ、ここに通知についての一文が入る。下記）

この設定はいつでも解除できます。

     ［キャンセル］［有効にする］
```

Android では、通知の許可の状態に応じた一文を本文に挟みます。

| 通知の許可 | 挟む一文 |
|---|---|
| ある | 録音中は、録音していることを通知でお知らせし続けます。 |
| ない | ほかのアプリを使っている時にも録音していることをお知らせし続けるため、通知の許可が必要です。「有効にする」を押すと端末の設定が開くので、momeo の通知を許可してください。 |

| 選択 | 結果 |
|---|---|
| キャンセル | 無効のまま。選択肢も無効の表示のまま |
| 有効にする（iOS、または Android で通知の許可がある） | 有効になり、帯のドットが赤に変わる |
| 有効にする（Android で通知の許可が無い） | 端末の設定が開く。momeo の通知を許可して戻ると、自動で有効になってダイアログが閉じる。許可せずに戻るとダイアログはそのまま |

- ダイアログの外側をタップしても閉じません。どちらかのボタンを押してもらい、同意を能動的な操作で取ります。
- ダイアログを開いたまま端末の設定から戻ってくると、通知の許可を確認し直し、本文の一文と「有効にする」の挙動が切り替わります。
- Android だけ通知の許可を条件にするのは、バックグラウンド録音中の常駐通知が Play の実質的な要件のためです。iOS に許可の条件はありません（→ `notes/background_recording/impl/phase1/step03_notification_permission_gate.md`）。

## シート下側 — ブラックボード

選択中のカードがそのまま操作の対象です。ブラックボードに映っている本文が、コピーや削除の対象になります。

- 選択中のカードの本文を、時系列順（古いものが上、新しいものが下）に並べます。日時は添えません。
- 全件を1枚のブラックボードに入れ、ひとかたまりとしてコピーされることを示します。枠線・角丸・余白・文字の大きさはメモ一覧のカードに揃え、地と文字の色だけ入れ替えます（黒地に白文字）。
- ブラックボードの下辺は、操作ボタンのエリアの上端に接します。高さは中身の量で変わりません。
- 本文どうしは空行1つでつなぎます。区切りはコピーした文字列にもそのまま入ります。
- 本文は文字列として選べません。持ち出す手段はブラックボードに触れることだけです。
- ブラックボードをタップするか押したままにすると、中身がまるごとクリップボードへ入ります。押したままの場合は、指を止めてすぐ反応します。
- 選択を外す手段は、メモ一覧側のタップと、帯の右側のタップです。ブラックボードに触れても選択は変わりません。
- 入りきらない場合はブラックボードの中をスクロールします。
- 0 枚のときも同じ位置に同じ大きさで置き、中身だけが空になります。空のブラックボードに触れてもコピーは起こりません。

### ブラックボードの上の一言

ブラックボードの上辺の外側、左端に短い文言を出します。場所は何も出ていないときも空けておき、ブラックボードの位置は動きません。

| 状況 | 文言 |
|---|---|
| 0 枚 | 選択したテキストが表示されます |
| 0 枚のまま触れた | テキストを選択するとコピーできます |
| コピーした直後 | クリップボードにコピーしました |

- 触れたときとコピーしたときの文言は 3.6 秒で消えます。続けて触れた場合は、最後の1回から数え直します。
- 1 枚以上選んでいる間は、コピーした直後だけ文言を出します。
- 文言の出入りと入れ替わりにフェードは挟まず、即座に切り替えます。

## 操作ボタン

シート下側の一番下、右端に削除を置きます。地は敷かず、赤い文字で「選択中の◯件を削除」と表示します（件数は選択枚数に追従します）。選択中のカードがあるときだけ出し、0 枚のときは何も出しません。

- 押すと確認ダイアログを表示し、了承したときだけ選択中のメモを削除します。
- コピーはここに置きません。ブラックボードに触れる操作に一本化し、入口を1つに絞ります。
- 選択の解除もここには置きません。帯の右側に一本化します。
- 削除は復元手段を持ちません。メモはデータごと消えます。削除後は選択が 0 枚になり、ブラックボードは空に戻ります。

### 確認ダイアログ

```text
選択中のメモを削除しますか？

一度削除すると復元できません。

     ［キャンセル］［削除する］
```

| 選択 | 結果 |
|---|---|
| キャンセル | 何も起こらない。選択もそのまま残る |
| 削除する | 選択中のメモをデータごと削除する |
