# momeo プロダクトオーバービュー

## momeo とは
momeo は、音声入力を第一に考えた「音声ファースト」のメモアプリケーションです。ユーザーがアプリを開いた瞬間から、できるだけ早くリスニングを開始し、シームレスに音声をテキストメモとして記録することを目的としています。

音声認識は OS の文字起こし（iOS は SpeechTranscriber、Android は端末内の SpeechRecognizer）で、端末の中だけで行います。言語のモデルは OS が端末にダウンロードして持ち、入っていれば実行は完全オフラインです。ユーザーに OS のダイアログで許可を求める権限はマイクのみです（Android で「バックグラウンド録音」を有効にするときだけ、端末の設定での通知の許可が別途必要になります）。

対応する OS は iOS 26 以上・Android 13 以上です。OS の文字起こしが使えない端末（端末内の音声認識が無い、優先する言語のどれにも対応していない）では、リスニングを始められません。

## アプリ全体の大まかな振る舞い
アプリは起動後、必要な権限を速やかに取得した上で、すぐに音声入力が可能な状態へと遷移します。ユーザーは録音開始ボタンを探す必要なく、そのまま話し始めることができます。

## メインアプリフロー
1. **アプリ起動**: ユーザーがアプリアイコンをタップ。
2. **スプラッシュシーケンス**: 起動時にアプリのコンセプトを伝える短いアニメーションテキストを表示。初回起動時はフルシーケンス、2回目以降は短縮表示。
3. **権限確認**: 必要な権限（マイクのみ）が許可されていない場合、権限を要求。
4. **準備ゲート**: リスニング直前に文字化エンジンの準備完了を確認。準備済みなら素通りし、未完了（OS が言語のモデルをダウンロード中など）なら待ち画面で足止めして完了後に自動で進む。OS の文字起こしが使えない端末では、その旨を表示して先へ進まない。
5. **リスニング画面**: メイン画面。アプリは直ちにリスニング状態となり、ユーザーの発話を待ち受ける。
6. **メモの記録**: ユーザーが話し始めると、次の文が入る場所に「.」が増えていき、発話が確定するとテキスト化されたメモが一覧の末尾に打ち出される。メモは日記のように1続きの文章として古い順に上から蓄積される（新しいメモほど下）。10秒以内に続けて話した分は、同じメモに書き足される。
