# リスニング画面のメモ一覧仕様（spike）

> spike ブランチ `spike/diary-memo` で試している仕様です。採用が決まるまで `notes/specs/` には反映しません。採用したときに `notes/specs/` で変わるところは、末尾の「採用したときに notes/specs/ で変わるところ」にまとめています。

## 概要

リスニング画面では、確定したメモを1件ずつ「ブロック」として縦に並べます。

1件のメモが1つのブロックになります。

- 無音が3秒続くと、1回の発話として確定します。
- 前の発話を書き足してから10秒以内に次の発話が始まったときは、同じメモの末尾に書き足します。10秒以上たっていたら、新しいメモを起こします。
- 書き足すときは、区切りの文字や改行を挟まず、そのままつなげます。
- 日付が変わっても、同じメモに書き足します。

ブロックは枠や背景を持たず、紙に直接書き留めたように本文だけを置きます。日記や、リングで綴じた単語カードの束のような印象を与えることを狙います。

ブロックごとの日付・時刻は表示しません。スクロールしている間だけ、画面の背景に、スクロールつまみの位置にあるメモの日付を1つだけ大きく出します（→「背景の日付」）。

## 一覧の並び

- 古いメモが上、新しいメモが下に並びます。
- 一覧は画面の下端に固定されています。新しいブロックは一番下に現れ、既存のブロックを上へ押し上げます。
- メモが少ないうちは、一覧全体が画面の下部に寄ります。
- ブロックの背景は透明で、画面の背景を流れる音量の波形が本文の後ろに透けて見えます。
- 日付の変わり目に区切りは挟みません。

iOS と Android では、本文の表示領域と右の縦線を画面の下端まで広げ、一覧の外側に安全領域の余白を設けません。

選択バーが出ている間は、バーが画面内に出ている高さに合わせて一覧の下端を押し上げます。

## ブロックの形

```text
 お婆ちゃんの家に行った。元気そうで   ◯
 よかった。                           │
                                      │
 耳と記憶は弱くなってて心配。         ●  ← 選択中（本文も太字）
 京都水族館に行ってソフトクリーム     ┃
 を食べた。                           ┃
                                      ┃
 予定なくなったから昼まで寝てた。     ◯
                                      │
```

| 要素 | 内容 |
|---|---|
| 本文 | 大きめの文字で表示する。選択中は太字にする |
| 右の線 | 画面の右寄りに、一覧を上から下まで貫く1本の縦線を引く |
| 丸 | 選択を切り替えるチェックボックス。各ブロックの右上に、右の線に通すように置く |

iOS と Android の本文の左余白は12、右余白は丸と縦線の領域を含めて34です（iOS は pt、Android は dp）。

- 各ブロックの範囲は、そのブロックの丸から、次のブロックの丸までです。丸があるところから、新しいメモが始まります。
- 丸の中心は、上のブロックの最後の行の文字の下端と、そのブロックの1行目の文字の上端のちょうど間に置きます。ブロック同士のすき間を上下のブロックで半分ずつ分け、線の区切り（選択したときの太い線の切れ目）を見た目の区切りにそろえるためです。
- 一番上のブロックには上のブロックがないので、2番目のブロックと同じだけ、1行目の文字の上端から離します。
- 一番下（最新）のブロックの丸より下にも線を伸ばします。そこも一番下のブロックの範囲だからです。
- 一番上（最古）のブロックの丸より上には、線を引きません。
- 丸を右側に置くのは、右手の親指で押しやすくするためです。

### スクロールつまみ

右の線の上に、横棒のつまみを重ねます。長い一覧を素早く行き来するためのものです。

- つまみの位置は、一覧のスクロール量を表します。一番上（最古）までさかのぼると上端、一番下（最新）では下端に来ます。
- つまみが動くのは、右の線が見えている範囲（録音設定パネルの下から、選択バーの上まで）です。下端がホームインジケーター・ナビゲーションバーに重なるときは、その上までにします（つまみを上へ動かす操作が、ホームへ戻る操作とぶつからないようにするため）。
- つまみは常に表示します。一覧がスクロールできないほど短いときは出しません。
- つまみを上下にドラッグすると、その位置に対応する場所まで一覧がスクロールします。長押しは要らず、指を置いてそのまま動かせば掴めます。
- つまみを動かさずに離したときは、つまみの下にある線・丸のタップとして扱い、ブロックの選択が切り替わります。
- 細い横棒でも掴めるよう、当たり判定は見た目より上下に広げます。
- OS 標準のスクロールバーは出しません。

### 背景の日付

画面の背景に、スクロールつまみの高さにあるブロックが始まった日付（最初の発話が始まった日）を大きく表示します。時刻は出しません。

```text
2026.09.26
```

- つまみの高さにあるブロックは、その高さより上で一番近い丸を持つブロックです。つまみを動かしたときも、一覧を指でスクロールしたときも、合わせて切り替わります。
- 指やつまみの操作でスクロールしている間だけ表示します。スクロールが止まって0.6秒たつと、0.2秒かけて消えます（現れるときも0.2秒）。
- 新しいメモが増えて一覧が末尾へ移るときは、表示しません。
- 文字は大きめ（48）で、本文の後ろで邪魔にならない薄さ（本文の色の10%）です。音量の波形と一緒に本文の後ろに透けて見え、触っても反応しません。
- 高さはつまみにそろえ、数字の上端をつまみの横棒の上端に合わせます。つまみを動かすと、日付も一緒に上下します。左右は、本文の表示領域（左余白12・右余白34の内側）の中央にそろえます。
- 画面が狭くて1行に収まらないときは、文字を縮めて収めます。
- 書き足しで同じブロックが長く続いても、出すのはブロックが始まった日付だけです（書き足した時刻は保存していないため）。

## ブロックの選択

右上の丸を押すと、そのブロックの選択・選択解除が切り替わります。

本文を押してもブロックの選択は切り替わりません。

iOS と Android の本文は、メモ全件を時系列順に並べた、編集できない1つのネイティブ文書として表示します。

本文の選択色、つまみ、語の選択、ドラッグ操作、拡大表示、メニューには OS の文字選択機能を使います。

本文を長押しすると、その位置の語や文字のまとまりを選択できます。

つまみをドラッグすると、ブロックをまたいで選択範囲を広げたり縮めたりできます。

画面の外にあるメモも文書に含み、選択中のスクロールで範囲を広げられます。

つまみの交差、メニューの項目・配置、選択色は OS の仕様とテーマに従います。

本文の行高は文字サイズの2倍、ブロック間の余白は24とし（iOS は1.5倍の行高にヒラギノの leading が加わって2倍になる）、そのレイアウトに対して OS が選択面を描きます。

文字選択の範囲は、文書内の文字位置と各メモの ID・本文の範囲を対応づけて保持します。

「コピー」は選択範囲と各メモの本文から文字列を組み立て、クリップボードへ入れます。

コピーしたあとも、文字選択は残ります。

選択色が付いているエリアの内側を1回タップすると、文字選択を解除し、選択色・つまみ・メニューを消します。

このタップによる解除はアプリ側で扱い、長押し・ダブルタップ・つまみのドラッグは OS の文字選択操作に従います。

ブロックをまたぐコピーでは、メモとメモの間を空行1つ（`\n\n`）でつなぎます（仮仕様）。

選択に1文字も含まないメモと、本文が空のメモは、コピーの区切りを増やしません。

本文に含まれる空白や改行は、そのままコピーします。

「すべて選択」は一覧の全件を対象にします。

Android の「すべて選択」は、そのときの表示位置を保ったまま範囲を広げます。

打ち出し中のブロックは、打ち終わるまで文字選択と「すべて選択」の対象に含めません。

選択範囲に入っているメモが削除された場合は、文字選択を解除します。

文字選択中の既存本文は選択を始めた時点の内容を保ち、その間の追記は選択を解除すると表示します。

新しいメモが一覧の一番下に増えても、既存の文字選択は保持します。

文字選択中や一覧をさかのぼっている間は、新しいメモの追加で末尾へ移動しません。

文字選択は丸によるブロック選択と別の状態として持ち、丸と選択バーの操作では文字選択を解除しません。

文字選択の操作は、丸による選択と選択バーの件数に影響しません。

| 状態 | 丸 | 本文 | 右の線（そのブロックの範囲） |
|---|---|---|---|
| 選択していない | 小さな黒丸 | 通常の太さ | 細い線 |
| 選択中 | ひと回り大きな黒丸 | 太字 | 少し太い線 |

- 選択しても、ブロックを囲む枠などは出しません。
- 続けて並んだブロックを選ぶと、太い線の区間が1本につながり、選んだ範囲がひと目で分かります。
- 1件以上選択している間は、画面の下端に選択バーが出て、選択中のメモをまとめて削除・コピーできます（→ `notes/specs/listening_selection_bar.md`）。
- 選択状態はアプリ全体で1つです。選択バーの「解除」を押すと、一覧側の選択もすべて外れます。
- 打ち出しの途中（後述「確定したときの表示」）のブロックも、丸を押せば選択できます。選択・コピーの対象は、表示途中の文字列ではなく本文の全文です。

## 画面上端の録音設定パネルと検索

一覧の上に、常設の検索フィールドは置きません。一覧は録音設定パネルのすぐ下から始まります。

録音設定パネルは、閉じているときも左右と下を線で囲み、下の角を丸めます（開いているときと同じ形）。

```text
┌──────────────────────────────┐
│ ● このアプリを使ってる時だけ録音  ⌄ │
╰──────────────────────────────╯
 お婆ちゃんの家に行った。…            ◯
```

## 確定したときの表示

発話が確定すると、一覧の末尾に新しいブロックが現れ、本文が1文字ずつ素早く打ち出されます（最大1.8秒以内に打ち終わる）。

書いている様子を見せるための演出です。

- この演出は、直前に確定した1件だけに付きます。
- アプリの起動時や画面の再表示で並ぶブロックは、打ち出さずに全文を表示します。

## 発話中の気配

発話が始まってから結果が届く（本文が現れる、または空の結果で終わる）まで、次の本文が入る位置に「.」を出します。

- 「.」は0.5秒ごとに1つずつ増え、10個まで増えたら0個に戻ります。本文と同じ文字・同じ色で描きます。
- 同じメモに書き足すときは、最新のブロックの最後の行の文字のすぐ後ろに続けます。
- 新しいメモを起こすときは、次のブロックの1行目にあたる位置（ブロック間の余白の下）に置き、丸は出しません。その間は、ブロック間の余白と1行分の高さを一覧の下に空けておきます。
- どちらに出すかは発話の始まりで決まり、発話の途中では動きません。
- 行に収まらない分は増やさず、収まる数まで増えたら0個に戻ります（折り返すと一覧の高さが変わって全体が上下するため）。
- 直前の発話を打ち出している間は出さず、打ち終わってから出します。
- 文字選択中は出しません。
- 「.」は本文に含めないので、コピーや「すべて選択」の対象になりません。

このほか、画面の背景を流れる音量の波形と、画面上端の状態行で点滅するドット（→ `notes/specs/listening_recording_settings_panel.md`）が、アプリが声を聞いていることを伝えます。

## 今後の検証項目

- 選択で本文を太字にすると、英数字の幅が広がって行の折り返しが変わり、ブロックの高さが変わることがあります（丸を押した瞬間に下のブロックがずれる）。気になる場合は、幅を変えない太らせ方を検討します。

## 採用したときに notes/specs/ で変わるところ

採用が決まったら、この文書を `notes/specs/listening_memo_list.md` として移し、次の4ファイルを直します。

### `listening_flow.md`

- 「画面構成」を、ブロックとして一覧に並ぶことの短い説明と、`listening_memo_list.md` への案内に置き換える
- 「メモの選択」「アクティブカードの出入り」「確定演出」の3節を削除する（内容は `listening_memo_list.md` が扱う）
- 「認識パイプライン」から、`onSpeechActiveChanged` でアクティブカードの出入りを駆動するという箇条を削除する
- 「確定フロー」の「確定済みメモカードとして表示する」を「ブロックとして表示する」にする
- 「関連ドキュメント」に `listening_memo_list.md` を足す
- 発話終了とみなす無音の長さ（`minSilenceDuration`）を1.5秒から3秒にする
- 「参照する既存デザインドキュメント」（`notes/design/03_screen_states/` の5件）はカード前提のため、残すかどうかを決める

### `listening_selection_bar.md`

- 「ボイスカード」「カード」を「ブロック」に置き換える
- 検索の絞り込みで隠れたメモも操作の対象に含むという箇条と、「検索フィールドへの入力中」の箇条を削除する
- 選択の参照先を `listening_flow.md` の「メモの選択」から `listening_memo_list.md` の「ブロックの選択」に変える。選択を切り替える操作は「カードのタップ」から「丸のタップ」にする
- バーの上辺の線を「選択していないボイスカードの枠線と同じ細い線」から「細い線」にする（基準にしていたカードの枠がなくなるため）
- 「関連ドキュメント」に `listening_memo_list.md` を足す

### `listening_recording_settings_panel.md`

- パネルが覆いかぶさる先、パネルの外を触ったときに届く先の「ボイスカード」を「ブロック」にする
- 「閉じているときは状態行の下に検索フィールドが続く」を「状態行の下に一覧が続く」にし、覆いかぶさる先から検索フィールドを外す
- 下の線と下の角を「開き具合に合わせて少しずつ濃く・丸く」から「開き閉じに関わらず常に引き、常に丸める」にする

### `overview.md`

- メインフロー6番「メモカード作成」を「メモの書き留め」にし、アクティブカードの記述を外す。確定したメモがブロックとして加わること、ブロックごとの日時は出さず、スクロール中だけ背景にスクロールつまみの位置にあるメモの日付を出すことを書く
