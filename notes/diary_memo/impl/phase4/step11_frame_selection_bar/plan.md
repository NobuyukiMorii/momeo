# Step 11 選択バーを枠で囲む

## 目的

画面下端の選択バーを、画面上端の録音設定パネルと同じ枠の形にそろえる。

上と下が同じ線・同じ丸みになり、画面全体が1つのデザインにまとまる。


| 項目    | 今           | 変更後                  |
| ----- | ----------- | -------------------- |
| 線を引く辺 | 上だけ         | 左・上・右                |
| 線の太さ  | 1.5         | 3（録音設定パネルと同じ）        |
| 上の角   | 四角          | 丸い（録音設定パネルの下の角と同じ丸み） |


## やること

- 選択バーの枠の線を、左・上・右に太さ3で引き、上の角を丸める
- バー全体の高さの計算に使う線の太さを、1.5 から 3 にする

## 参照する `spike/diary-memo` のコード


| ファイル                                    | 場所                                            |
| --------------------------------------- | --------------------------------------------- |
| `lib/widgets/listening_selection_bar.dart` | 枠の線と角の丸み（19〜28行目）                            |
|                                         | 全体の高さ `_barHeight`（60〜62行目）                   |
|                                         | 枠を付けるところ `_buildBar` の `BoxDecoration`（381〜388行目） |


同じファイルの「バーが画面内に出ている高さ」（`listeningSelectionBarVisibleHeight`）は、一覧を画面の下端まで広げる step で扱う。
