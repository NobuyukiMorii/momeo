# Step 19 録音で一覧が変わっても、文字選択を保つ

## 目的

文字を選んでいる最中に、録音で新しいメモが増えたり書き足されたりしても、選択が外れないようにする。

録音はいつも続いているので、これが無いと落ち着いて選べない。


| 選んでいる間に起きること    | どうなるか                           |
| --------------- | ------------------------------- |
| 一番下に新しいメモが増える   | 選択はそのまま。一番下へは移動しない               |
| 選んでいるメモに書き足される  | 選んだ時点の本文のまま出す。書き足した分は、選択を外すと出る    |
| 選んでいるメモが削除される   | 選択を外す                           |


## やること

- 文書を丸ごと入れ替えず、前と同じ先頭部分は残して、変わったところから後ろだけを差し替える（OS の選択状態を保てる）
- 差し替える前の選択の両端を「どのメモの何文字目か」で覚えておき、差し替えた後に同じ場所へ置き直す
- 選んでいる間は、選んだ時点の本文を覚えておき、その本文のまま出す
- 選択が外れたら、止めていた更新（書き足しなど）をまとめて出す
- 選んでいる間は、新しいメモが増えても一番下へ移動しない
- Android：置き直した選択の端へ、OS が勝手にスクロールしないようにする
- Android：行高・太字の span は、変わったブロックだけ付け直す（step 12 では毎回文書ごと作り直している）
