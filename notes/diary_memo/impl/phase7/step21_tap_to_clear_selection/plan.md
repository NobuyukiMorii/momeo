# Step 21 タップで選択を外す

## 目的

文字選択を、迷わず外せるようにする。


| 操作                     | 動き                          |
| ---------------------- | --------------------------- |
| 選択色が付いているところを1回タップ     | 文字選択を外す（選択色・つまみ・メニューが消える）   |
| 録音設定パネルに触れる            | 文字選択を外す                     |
| 長押し・ダブルタップ・つまみのドラッグ    | 今までどおり OS の文字選択の操作          |
| 丸を押す・選択バーを使う           | 文字選択は外さない（丸の選択とは別の状態）       |


- 選択色が付いていれば、文字の無いブロック間の余白をタップしても外れる

## やること

- iOS・Android：タップした点が、OS が選択色を付けている面に入っているかを調べる
- iOS・Android：指を置いてから選択が変わっていない1回タップのときだけ、選択を外す（ダブルタップなどと取り違えない）
- Dart：画面から「文字選択を外して」と頼める窓口（コントローラー）を用意し、ネイティブへ伝える
- Dart：録音設定パネルに触れたら、その窓口で選択を外す
