# Step 20 メモをまたいでコピー・すべて選択

## 目的

OS のメニューの「コピー」「すべて選択」を、メモの区切りを踏まえた動きにする。

文書の中ではメモとメモを改行1つでつないでいるので、OS に任せたままだと、コピーした文字列のメモの区切りが分かりにくい。


| 操作       | 動き                                            |
| -------- | --------------------------------------------- |
| コピー      | 選んだ範囲に掛かる各メモの部分を取り出し、空行1つ（`\n\n`）でつなぐ          |
| コピーした後   | 文字選択は残す                                       |
| すべて選択    | 一覧の全件を選ぶ（画面の外のメモも含む）                          |
| すべて選択（Android） | 今の表示位置を保ったまま選ぶ                                |
| すでに全件を選んでいるとき | 「すべて選択」を出さない（iOS）                             |


- 選択に1文字も含まないメモと、本文が空のメモは、区切りを増やさない
- 本文に含まれる空白や改行は、そのままコピーする

## やること

- Dart：区切りの文字列（`\n\n`）を決め、文書に入れてネイティブへ渡す
- iOS：メニューの「コピー」「すべてを選択」を上書きし、出すかどうかも決める
- Android：メニューの「コピー」「すべて選択」を受け取り、アプリ側で行う
