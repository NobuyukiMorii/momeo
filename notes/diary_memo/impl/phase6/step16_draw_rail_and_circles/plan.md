# Step 16 縦線と丸を描く

## 目的

一覧の右寄りに1本の縦線を引き、各ブロックの始まりに丸を置く。

丸があるところから新しいメモが始まる、とひと目で分かるようにする。押して選ぶのは次の step 17。

```text
 お婆ちゃんの家に行った。元気そうで   ◯
 よかった。                           │
                                      │
 耳と記憶は弱くなってて心配。         ◯
 京都水族館に行ってソフトクリーム     │
 を食べた。                           │
```

## やること

- 縦線と丸の位置・太さ・大きさを定数にまとめる
- 丸の高さを求める：上のブロックの最後の行の文字の下端と、そのブロックの1行目の文字の上端の、ちょうど間
- 一番上のブロックは、2番目のブロックと同じだけ文字の上端から離す
- 縦線は一番上の丸から始め、一番下の丸より下まで伸ばす
- iOS は縦線用の View を一番手前に重ね、スクロールしても右端に留める。Android は本文の View の上に直接描く

この step では、丸はすべて同じ「選択していない」見た目で描く。
