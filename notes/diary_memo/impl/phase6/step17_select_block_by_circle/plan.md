# Step 17 丸を押すと選択・太字になる

## 目的

丸を押してメモを選べるようにし、選んだメモがひと目で分かるようにする。

step 12 から使えなくなっていた選択バー（削除・コピー）が、ここでまた使えるようになる。


| 状態     | 丸         | 本文    | 右の線（そのブロックの範囲） |
| ------ | --------- | ----- | -------------- |
| 選択していない | 小さな黒丸     | 通常の太さ | 細い線            |
| 選択中    | ひと回り大きな黒丸 | 太字    | 少し太い線          |


```text
 お婆ちゃんの家に行った。元気そうで   ◯
 よかった。                           │
                                      │
 耳と記憶は弱くなってて心配。         ●  ← 選択中
 京都水族館に行ってソフトクリーム     ┃
 を食べた。                           ┃
```

## やること

- iOS・Android：縦線と丸の上のタップを受け取り、その高さより上で一番近い丸のメモ id を Dart へ知らせる
- Dart：知らせを受けて選択を切り替える（選択の状態は今までどおりページが持つ）
- Dart：各ブロックが選ばれているかを、文書に入れてネイティブへ渡す
- iOS・Android：選択中のブロックは、本文を太字、丸を大きく、線を太くする
- 続けて並んだブロックを選ぶと、太い線が1本につながる

本文を押しても、ブロックの選択は切り替わらない。
