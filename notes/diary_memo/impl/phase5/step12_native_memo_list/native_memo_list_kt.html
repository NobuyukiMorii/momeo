NativeMemoList.kt

Dart から届いたメモ一覧を、Android の部品で1枚の文章として画面に出すファイル。

流れ

Dart がメモ一覧を送るupdate
→
受け取るNativeMemoList
→
メモを1枚の文章にするMemoDocumentView
→
画面に出して、一番下までスクロール

「1枚の文章にする」とは

blocks: [
  { id: 1, text: "お婆ちゃんの家に行った。" },
  { id: 2, text: "耳と記憶は弱くなってて心配。" },
]
→
お婆ちゃんの家に行った。
ブロックの間 24
耳と記憶は弱くなってて心配。

メモ1件 = ブロック1つ。改行でつなぎ、行の高さは文字の2倍、ブロックの下に 24 空ける。書体は Noto Sans JP。

ファイルの中身（上から順）

33–69定数　余白・行の高さ・書体など
74–83NativeMemoListFactory　作り手（MainActivity が登録する）
95–123NativeMemoList　Dart との窓口。update を受け取って下へ渡す
128–206MemoDocumentView　本文。1枚の文章を作って出す ← 中心
212–224MemoLineHeightSpan　行の高さとブロックの間を決める
