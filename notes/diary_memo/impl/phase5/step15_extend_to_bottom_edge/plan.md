# Step 15 一覧を画面の下端まで広げる

## 目的

一覧の下に残っていた白い帯をなくし、本文が画面の下端まで流れるようにする。


| 項目              | 今                          | 変更後                               |
| --------------- | -------------------------- | --------------------------------- |
| 一覧の下端           | ホームインジケーター・ナビゲーションバーの上で切れる | 画面の下端まで                           |
| 一番下までスクロールしたとき   | （下端で切れているので気にしなくてよい）        | 最新の行は、ホームインジケーター・ナビゲーションバーの上に離して止まる |
| スクロールの途中        | （同上）                       | 本文はバーの下を通り抜けて流れる                  |
| 選択バーが出ている間      | 安全領域より上に出た分だけ押し上げる           | バーが画面に出ている高さの分だけ押し上げる             |


## やること

- Dart：一覧の外側に付けていた下の余白（安全領域の分）をやめる
- Dart：選択バーが画面に出ている高さ（安全領域を含む）を返す関数にし、その分だけ一覧を押し上げる
- iOS・Android：一番下までスクロールしたときだけ、最新の行をホームインジケーター・ナビゲーションバーの上へ離す（本文の下の余白に、重なっている高さを足す）
- iOS・Android：一覧の高さが変わったとき（選択バーの出入りなど）、一番下を見ていたら一番下のまま保つ
