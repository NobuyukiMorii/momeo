# 日記型メモ一覧 実装計画

`spike/diary-memo` で作った日記型の画面を、`main` で少しずつ作り直す。

- 1 step = 1 commit = 1つの目的
- お手本は常に `spike/diary-memo` のコード
- 実装中の調整で spike と違ってよい。ただし、やり残し・検討漏れは無くす
- 各 step は `phaseN/stepNN_名前/` に置く（計画は `plan.md`。説明資料の HTML は、頼んだときだけ作る）

---

## 全体の流れ

```text
Phase 1  下準備
Phase 2  発話のまとめ方
Phase 3  検索をなくし、録音設定パネルを整える
Phase 4  選択バーを整える
Phase 5  ネイティブ一覧へ差し替え   ← 一番大きい
Phase 6  ブロック選択（丸と縦線）
Phase 7  文字選択とコピー
Phase 8  スクロールつまみと背景の日付
Phase 9  書いている気配
Phase 10 その他
```

---

## Phase 1 下準備

画面の作りと関係ない、小さな変更を先に済ませる。


| step | やること               |
| ---- | ------------------ |
| 1    | 縦画面に固定する           |
| 2    | 書体をそろえる（iOS はヒラギノ、Android は Noto Sans JP） |
| 3    | 読み込み中も「momeo」のまま待つ |


## Phase 2 発話のまとめ方

どこで区切って、どこに書き足すかを変える。


| step | やること                  |
| ---- | --------------------- |
| 4    | 無音3秒で確定する             |
| 5    | 1秒未満の音は発話と見なさない       |
| 6    | 10秒以内の発話は同じメモに書き足す    |
| 7    | 発話と発話を空行で区切らない        |
| 8    | 日付が変わっても同じメモに書き足す     |




## Phase 3 検索をなくし、録音設定パネルを整える

カード一覧を外す前に、その上にある検索を片付ける。あわせて、画面の上の録音設定パネルを整える。


| step | やること             |
| ---- | ---------------- |
| 9    | 検索フィールドを消し、録音設定パネルを整える |
| 10   | 検索の絞り込みを消す（しくみ）      |




## Phase 4 選択バーを整える

画面の下端に出る選択バーを、録音設定パネルと同じ枠の形にそろえる。


| step | やること      |
| ---- | --------- |
| 11   | 選択バーを枠で囲む |


## Phase 5 ネイティブ一覧へ差し替え

Flutter のカード一覧を、OS の部品で作った一覧に置き換える。


| step | やること                |
| ---- | ------------------- |
| 12   | ネイティブ一覧を作り、画面を差し替える |
| 13   | 使わなくなったカード関連を消す     |
| 14   | 「カード」を「ブロック」に呼び変える  |
| 15   | 一覧を画面の下端まで広げる       |


※ step 12〜16 の間は丸が無いので、選択バーは一時的に使えない。

## Phase 6 ブロック選択

右の縦線と丸で、メモを選べるようにする。


| step | やること          |
| ---- | ------------- |
| 16   | 縦線と丸を描く       |
| 17   | 丸を押すと選択・太字になる |




## Phase 7 文字選択とコピー

本文の文字を、OS 標準の操作で選んでコピーできるようにする。


| step | やること             |
| ---- | ---------------- |
| 18   | 文字を選べるようにする      |
| 19   | 録音で一覧が変わっても、文字選択を保つ |
| 20   | メモをまたいでコピー・すべて選択 |
| 21   | タップで選択を外す        |




## Phase 8 スクロールつまみと背景の日付

長い一覧を素早く行き来し、いつのメモか分かるようにする。


| step | やること             |
| ---- | ---------------- |
| 22   | 縦線の上につまみを置く      |
| 23   | スクロール中だけ背景に日付を出す |




## Phase 9 書いている気配

聞いている・書いている様子を見せる。


| step | やること           |
| ---- | -------------- |
| 24   | 確定したメモを1文字ずつ出す |
| 25   | 話している間「.」を増やす  |




## Phase 10 その他


| step | やること                    |
| ---- | ----------------------- |
| 26   | 開発用の画面を合わせ、使っていないファイルを消す |
