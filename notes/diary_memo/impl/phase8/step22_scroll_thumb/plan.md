# Step 22 縦線の上につまみを置く

## 目的

長い一覧を、すばやく行き来できるようにする。

右の縦線の上に横棒のつまみを重ね、上下にドラッグするとその位置までスクロールする。

```text
 お婆ちゃんの家に行った。元気そうで   ◯
 よかった。                           │
                                     ─┼─  ← つまみ
 耳と記憶は弱くなってて心配。         ◯
```


| 項目           | 動き                                          |
| ------------ | ------------------------------------------- |
| つまみの位置       | 一番上（最古）までさかのぼると上端、一番下（最新）では下端              |
| 動く範囲         | 縦線が見えている範囲。ホームインジケーター・ナビゲーションバーの上まで          |
| 出すとき         | いつも出す。スクロールできないほど短い一覧では出さない                  |
| ドラッグ         | 指を置いてそのまま動かせば掴める（長押しは要らない）                   |
| 動かさずに離したとき   | つまみの下にある線・丸のタップとして扱う（ブロックの選択が切り替わる）          |
| 当たり判定        | 細い横棒でも掴めるよう、見た目より上下に広げる                     |
| OS 標準のスクロールバー | 出さない                                        |


## やること

- iOS・Android：OS 標準のスクロールバーを消す
- iOS・Android：つまみの位置・動く範囲・当たり判定を求め、縦線の上に描く
- iOS・Android：つまみの上で指が動いたときだけ、一覧のスクロールより先にドラッグとして受け取る
- ドラッグ中は慣性スクロールを止め、指を置いた位置とつまみの中心のずれを保ったまま動かす

Dart は変わらない。
