# Step 9 検索フィールドを消し、録音設定パネルを整える

## 目的

一覧の上の検索フィールドをなくし、一覧が録音設定パネルのすぐ下から始まるようにする。

文字を入力する場面が無くなるので、キーボードのための処理も一緒に消す。

今は検索フィールドの枠が、録音設定パネルと一覧の境目の線を兼ねている。検索フィールドと一緒にその線も無くなるので、パネルを閉じていても枠で囲むようにする。

あわせて、パネルの状態行（「● このアプリを使ってる時だけ録音 ⌄」の行）を低くし、一覧を広く見せる。

## やること

### 消すもの


| 消すもの               | 場所                                                |
| ------------------ | ------------------------------------------------- |
| 検索フィールドの部品         | `lib/widgets/listening_search_field.dart`（ファイルごと） |
| 検索フィールドの配置と、その分の余白 | `lib/pages/listening/listening_page.dart`         |
| 入力中の文字・カーソルの状態     | `lib/pages/listening/listening_page.dart`         |
| キーボードの開閉の検知        | `lib/pages/listening/listening_page.dart`         |
| キーボードで画面を縮めない設定（`resizeToAvoidBottomInset`） | `lib/pages/listening/listening_page.dart` |
| 一覧や録音設定パネルに触れたらカーソルを外す処理（`_exitKeywordInput` を呼ぶ `Listener`） | `lib/pages/listening/listening_page.dart` |
| キーボードに触れたコメント（「入力中も一覧を動かさない」） | `lib/widgets/listening_selection_bar.dart` |
| 起動時にキーボードを閉じる処理    | `lib/main.dart`                                   |


### 録音設定パネルの枠と状態行


| 項目      | 今                   | 変更後        |
| ------- | ------------------- | ---------- |
| 閉じているとき | 左右の線だけ（下は検索フィールドの枠） | 左右と下を線で囲む  |
| 下の角     | 開くにつれて少しずつ丸くなる      | いつも丸い      |
| 下の線     | 開くにつれて少しずつ濃くなる      | いつも同じ濃さで引く |
| 状態行の高さ  | 28（文字の行 18 + 上下の余白 10） | 21（文字の行 12 + 下の余白 9） |


- 閉じているときのパネルの高さに、下の線の太さを足す（状態行の高さを `_stateRowHeightOf` に分けて、それに線の太さを足す形にする）
- 状態行の文字の行の高さを文字サイズと同じにし、余白を下だけにする
- 山形（⌄）は行より大きいので、行からはみ出させて上下中央にそろえる

検索語で絞り込むしくみは、次の step 10 で消す。この step のあとは検索語が常に空になるので、絞り込みは何もしない状態になる。
