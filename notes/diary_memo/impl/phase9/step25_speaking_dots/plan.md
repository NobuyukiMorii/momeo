# Step 25 話している間「.」を増やす

## 目的

話している間、アプリがちゃんと聞いていることを、本文が入る場所で見せる。

step 12 で無くなったアクティブカードの代わり。

```text
 耳と記憶は弱くなってて心配。......    ◯      ← 同じメモに書き足すとき
```

```text
 耳と記憶は弱くなってて心配。         ◯
                                      │
 ......                               │      ← 新しいメモを起こすとき（丸は出さない）
```


| 項目       | 動き                                                   |
| -------- | ---------------------------------------------------- |
| 出す間      | 話し始めてから、結果が届く（本文が現れる、または空の結果で終わる）まで                  |
| 増え方      | 0.5秒ごとに1つ増え、10個で0個に戻る。行に収まらないときは、収まる数で戻る              |
| 出す場所     | 同じメモに書き足すときは、最新のブロックの最後の文字の後ろ。新しいメモのときは、次のブロックの1行目 |
| 場所が決まるとき | 話し始めたとき。話している途中では動かない                                |
| 出さないとき   | 直前の発話を打ち出している間（打ち終わってから出す）、文字選択中                     |
| 見た目      | 本文と同じ文字・同じ色                                          |
| コピー      | 本文ではないので、コピーや「すべて選択」の対象にならない                         |


## やること

- Dart：状態に「発話が終わり、結果を待っているか」（`awaitingTranscription`）を足す
- Dart：出すか・どこに出すか（出さない／書き足し／新しいメモ）を決めて、文書に入れて送る
- iOS・Android：「.」を描き、0.5秒ごとに増やす
- iOS・Android：新しいメモの位置に出す間は、ブロック間の余白と1行分の高さを一覧の下に空けておく
