# Step 24 確定したメモを1文字ずつ出す

## 目的

発話が確定したとき、本文を1文字ずつ素早く打ち出し、書いている様子を見せる。

カード一覧にあった演出を、ネイティブ一覧でも出せるようにする（step 12 からいったん無くなっていた）。


| 項目          | 動き                                   |
| ----------- | ------------------------------------ |
| 打ち出すメモ      | 直前に確定した1件だけ（書き足したときは、書き足した分から）       |
| 速さ          | 最大 1.8秒以内に打ち終わる                      |
| 起動時・画面の再表示  | 打ち出さずに全文を出す                          |
| 打ち出している間    | そのメモは文字選択・「すべて選択」の対象にしない             |
| 丸での選択・コピー   | できる。対象は表示途中の文字ではなく本文の全文              |


## やること

- Dart：今ある打ち出しの部品（`TypewriterText`）に、表示途中の本文から好きな部品を組み立てられる入口（`builder`）を足す
- Dart：ネイティブ一覧をその部品で包み、打ち出し中のメモだけ表示途中の本文を文書に入れて送る
- Dart：打ち出し中のメモは「文字選択の対象にしない」と文書に入れる
- Dart：打ち終わったら、ページ経由で Notifier に知らせる（再表示で打ち直さない）
- iOS・Android：「文字選択の対象にしない」を受け取り、選択・コピーの対象から外す

ネイティブ View は、打ち出しの開始・終了で作り直さない（部品の階層を保つ）。
