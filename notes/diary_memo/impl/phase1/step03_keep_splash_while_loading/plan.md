# Step 3 読み込み中も「momeo」のまま待つ

## 目的

スプラッシュのあと、モデルを読み込む数秒のあいだも「momeo」を出したままにする。

「準備しています」「もうすぐ完了します」と文言が切り替わらず、スプラッシュの続きに見えるようにする。

## やること


| 今                                   | 変更後                  |
| ----------------------------------- | -------------------- |
| 準備しています（DL前）                        | momeo                |
| もうすぐ完了します（DL後、読み込み中）                | momeo                |
| DL中の %・再試行・再起動のお願い                  | そのまま                 |


- 待ち画面のフェーズを5つから4つにする（「準備中」「もうすぐ完了」を1つの「読み込み中」にまとめる）
- 「momeo」の文字は、スプラッシュと待ち画面で同じ定数 `splashAppName` を使う
- 開発用カタログの見本も合わせる
